## 这张图决定了什么

**PIR 静默不等于没人。** 一半以上的活动区域是盲区，人在主卧/厨房/厕所时两个 PIR 都看不见。

实测数据坐实了这点：

```
最长「在家但无 PIR 移动」  7.4 小时（08-24 02:02→09:26，睡觉）
实际出门                  5.4 小时（08-25 10:35→15:28）
```

**在家的静默比出门还长** → 任何基于 `quiet_s` 单阈值的分类器在这套硬件下都是**证明无效**的，
不管阈值定在哪都会把睡觉判成出门。别再往这个方向investment。

## 决定性实测（2026-08-25）：设备日志判断不了「没人」

把 7 个信号全部并起来测——客厅PIR、游戏房台灯、电视、音箱、洗衣机、洗衣机门、门锁：

```
确认在家的 34.4 小时里，全信号同时静默的最长空档 = 13.5 小时
        08-24 11:01 → 08-25 00:29（用户确认「肯定在家」）
对比：实际出门                                  =  5.4 小时
```

**融合之后比单信号更糟**（PIR 单独是 7.4h，融合后 13.5h）。人在家 13.5 小时没碰过
任何设备，而出门才 5.4 小时——两者在这个特征上完全无法分离。

这不是算法问题，是**信息本身不存在**。人在家不代表会去碰设备，主卧/厨房/厕所又全是盲区。
再怎么加权、上什么模型都变不出不存在的信息。

### 因此：设备信号只能单向使用

```
有信号活动      → 确定有人       ✅
没有任何信号    → 什么都推不出    ❌ 不能当「没人」
```

`quiet_s`（静默越久越可能没人）**方向是错的**，只能当「有人」的快速确认，不能当「没人」的依据。

### 唯一能判「没人」的是手机在不在 WiFi 上

理由只有一条：**覆盖全屋，且不需要人碰任何东西**。人在主卧躺着不动时，PIR 瞎、设备静默，
但手机还在网上。所有信号里只有它具备这个性质。

### 目标架构

```
手机在网                        → 有人（主判据）
设备有活动                      → 有人（补强，确认更快）
门锁事件                        → 转换时刻（精确时钟）
手机不在网 + 门已上锁 + 设备静默  → 没人（三者同时成立才下结论）
```

### 方法论备注

这个结论来自「拿历史存量问用户」而不是攒新数据——两小时得到了原本要几周才能得到的
**否定性结论**，排除了单阈值和纯设备融合两条路。以后遇到类似问题，先翻 recorder。
